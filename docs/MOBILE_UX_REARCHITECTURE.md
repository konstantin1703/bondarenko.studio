# BND Studio — mobile UX rearchitecture

## Goal

Сделать мобильную версию простой для первого прохода, но не примитивной: меньше когнитивной нагрузки, меньше возвратного скролла, понятнее интерактивы, спокойнее фон и последовательный русский интерфейс.

## Problems to solve

1. Мобильный WebGL/material background читается как случайные дуги, полосы и круги и спорит с контентом.
2. Diagnostics и Capabilities требуют выбирать пункт сверху, а читать результат далеко ниже.
3. Brief допускает только один тип проекта, хотя реальный проект может включать несколько форматов.
4. Brief на телефоне слишком длинный и ощущается как анкета.
5. CTA в Hero появляется до того, как пользователь понял предложение.
6. Systems использует переключатели, смысл и результат которых неочевидны.
7. Пользовательский интерфейс смешивает русский и служебный английский.
8. На телефоне сайт выглядит как длинный лендинг, а не как собранная digital-система.

## Product decisions

### Mobile material system

- На мобильных до 680px отключить крупные WebGL-формы в основных контентных секциях.
- Вместо них использовать локальный CSS-material: мягкое пятно света, тонкая сетка/градация, зерно и короткие акцентные штрихи.
- Фон не должен пересекать текст крупными яркими дугами.
- Desktop/WebGL art сохраняется без изменения.

### Diagnostics / Capabilities

- Desktop сохраняет master-detail механику.
- Mobile превращается в inline accordion: выбор и расшифровка находятся в одном месте.
- Выбранный пункт раскрывает текст и модули сразу под собой.
- Отдельная нижняя detail-панель на мобильном скрывается.

### Hero

- Удалить ранний CTA «Собрать проект» из hero-content.
- Оставить первый экран как объяснение системы и переход к следующему содержательному блоку.
- Project CTA остаётся в поздних точках маршрута и на desktop-header там, где уже существует.

### Brief

- Разрешить выбирать несколько форматов проекта.
- Сократить 5 шагов до 4:
  1. Форматы проекта — multi-select.
  2. Состав решения — модули + приоритеты на одном экране.
  3. Рамки — сроки + бюджет.
  4. Контакт — имя, контакт, контекст.
- На мобильном rail превратить в компактный progress/header вместо вертикальной навигации.
- API принимает 1–6 форматов и передаёт их все в Telegram.

### Systems

- Перевести route labels на русский и объяснить, что переключатель меняет архитектурный контур.
- На мобильном убрать ощущение «трёх непонятных кнопок»: каждая карточка получает явное название и короткое пояснение; выбранный контур показывает описание рядом.

### Language

- Видимый интерфейс — русский.
- Допустимые исключения: бренд BND Studio и индустриальные аббревиатуры/имена технологий: AI, API, CRM, Web, Telegram, YouTube, Next.js, WebGL, QA.
- Служебные подписи типа ACTIVE ROUTE / OUTPUT / CONTINUE / BRIEF / SYSTEMS / STUDIO переводятся.

## Acceptance criteria

- На 320/390/430px нет крупных фоновых дуг, пересекающих текст.
- Diagnostics/Capabilities читаются без возврата к верхнему списку после каждого выбора.
- Brief позволяет выбрать несколько форматов и отправляет массив форматов без потери данных.
- Brief имеет 4 шага и мобильный progress занимает минимум вертикального пространства.
- В Hero отсутствует CTA «Собрать проект».
- Systems переключатели понятны без дополнительного объяснения пользователя.
- Основной UI на русском.
- Минимальные touch-targets остаются >=44x44px.
- Нет horizontal overflow на 320px.
- Existing performance/WebGL, accessibility, metadata, link-integrity and route QA remain green.
