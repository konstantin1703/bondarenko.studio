# BND.STUDIO Visual Reconstruction V1

Отдельный production-oriented preview новой главной страницы. Ветка не изменяет текущий `main` и не заменяет рабочий сайт.

## Что реализовано

- Hero с четырьмя управляемыми scroll-состояниями: CORE, ARCHITECTURE, AI ENGINE, SYSTEM MODE;
- отдельные HTML/SVG HUD-слои, инженерная сетка, маршруты, модули и системные статусы;
- непрерывный бело-бирюзовый градиент внутри строк заголовка;
- интерактивная панель «Что можно изменить» с шестью сценариями;
- продуктовая архитектура с четырьмя направлениями;
- пятишаговый конфигуратор проекта с живым предварительным брифом;
- адаптивные desktop/tablet/mobile состояния;
- поддержка `prefers-reduced-motion`;
- отсутствие выдуманных метрик и универсального фиктивного стека.

## Ассеты

Четыре состояния куба очищены через Adobe и размещены в Cloudinary. Они используются как временный согласованный набор для визуальной реконструкции. Финальная production-версия должна быть заменена четырьмя рендерами одной Blender-модели с единой камерой, геометрией и освещением.

## Запуск

Откройте `studio-preview-v2/index.html` через локальный HTTP-сервер, например:

```bash
python -m http.server 8000
```

Затем откройте:

```text
http://localhost:8000/studio-preview-v2/
```
