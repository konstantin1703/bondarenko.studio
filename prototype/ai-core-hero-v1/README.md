# BND AI Core Hero Prototype V1

Контрольный scroll-прототип на базе четырёх утверждённых мокапов.

## Запуск

1. Скачать полный ZIP-пакет из чата.
2. Распаковать архив.
3. Запустить `start-viewer.bat`.
4. Откроется `http://localhost:8000`.
5. Прокрутить страницу вниз и обратно вверх.

## Что проверяется

- последовательность состояний: Собран → Активирован → Частично раскрыт → System Mode;
- плавность переходов;
- скорость раскрытия;
- обратимость по скроллу;
- лёгкий параллакс от курсора;
- общая композиция Hero.

## Ограничение V1

Это точный визуальный контрольный прототип: используются целые утверждённые мокапы. В производственной версии куб будет отделён от интерфейса, а текст, кнопки и подписи станут настоящими HTML-элементами.
