# ТЗ — BND AI CORE HERO IMPLEMENTATION

## Source of truth
Четыре утверждённых мокапа являются визуальным эталоном состояний 01–04.

## Подход
Гибридная реализация:
- пререндеренные состояния/кадры куба;
- HTML/CSS для интерфейса и типографики;
- JavaScript scroll controller;
- курсорный параллакс и динамический свет;
- дальнейшее расширение до промежуточной последовательности кадров.

## Этап V1
- использовать четыре целых мокапа как контрольные кадры;
- плавно смешивать соседние состояния по скроллу;
- обеспечить обратную прокрутку;
- проверить длительность и композицию.

## Этап V2
- получить чистые cube-only изображения с прозрачным фоном;
- перенести шапку, текст, кнопки и статусы в HTML;
- добавить линии модулей как SVG/DOM;
- адаптировать под мобильные экраны.

## Этап V3
- создать 24–48 промежуточных кадров между ключевыми состояниями;
- заменить crossfade на canvas image sequence;
- добавить переход Hero → «ЧТО МОЖНО ИЗМЕНИТЬ»;
- оптимизировать WebP/AVIF, preload и memory budget.

## Критерии приёмки V1
- старт в состоянии 01;
- один шаг колеса не перескакивает сразу в 04;
- все четыре состояния визуально достижимы;
- обратный скролл возвращает предыдущие состояния;
- интерфейс не дёргается;
- 60 FPS на настольном браузере при загруженных изображениях.
