# BND AI Sphere — WebGL Viewer V2

## Цель

Сделать предсказуемую и естественную scroll-driven анимацию утверждённой V6-сферы без runtime-управления десятками Blender AnimationAction.

## P0 — motion engine

- При загрузке сфера всегда закрыта.
- Четыре Blender-состояния считываются один раз после загрузки GLB.
- Для каждого анимируемого узла сохраняются position, quaternion и scale в состояниях Closed, Hover, Partial и System.
- В runtime детали управляются прямой интерполяцией сохранённых transform-наборов.
- Обратный скролл должен собирать сферу тем же путём.
- Последние 10% скролла — стабилизация System Mode без дальнейшего разлёта.

## P0 — тайминг

- 0–22%: Closed → Hover, минимальное раскрытие.
- 22–68%: Hover → Partial, основное раскрытие оболочки.
- 68–90%: Partial → System, включение архитектуры и линий.
- 90–100%: удержание System Mode и работа импульсов.

## P1 — естественность

- Smootherstep easing вместо линейного движения.
- Индивидуальные задержки панелей по имени и индексу.
- Ядро реагирует раньше линий данных.
- Линии данных активируются позже оболочки.
- Damping между скроллом и моделью.
- Idle-движение почти останавливается во время активной прокрутки.

## P1 — интерактивность

- Hover работает только в верхнем закрытом состоянии.
- Курсор даёт ограниченный parallax, без свободного вращения.
- В System Mode импульсы и внутренние кольца продолжают движение.

## Проверка

1. Старт в Closed.
2. Один шаг колеса не раскрывает сферу целиком.
3. Каждый диапазон скролла физически меняет модель.
4. Обратный скролл плавно собирает объект.
5. System Mode не перескакивает в начало.
6. FPS на desktop остаётся стабильным.
