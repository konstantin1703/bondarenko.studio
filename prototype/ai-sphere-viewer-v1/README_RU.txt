BND AI Sphere WebGL Viewer V2

ЗАПУСК
1. Запустите start-viewer.bat.
2. Дождитесь открытия localhost:8000.
3. При необходимости нажмите Ctrl+F5.

ПРОВЕРКА
- При старте сфера должна быть собрана.
- Медленно прокручивайте страницу: раскрытие должно происходить постепенно.
- Прокрутите назад: сфера должна собраться.
- В конце должны появиться подписи и двигаться импульсы.
- Кнопки Собрана / Hover / Частично / System переводят viewer к контрольным состояниям.

Для загрузки Three.js требуется интернет. GLB и poster находятся локально в assets/.
