# BND AI SPHERE — ТЗ НА WEBGL VIEWER V1

## 1. Цель

Собрать отдельный контрольный WebGL-viewer для утверждённой 3D-модели `BND_AI_Sphere_v6.glb` до интеграции в Hero BND.STUDIO.

Viewer должен проверять не дизайн сайта, а качество реального поведения объекта в браузере:

- загрузку и стабильность GLB;
- четыре состояния сферы;
- плавность раскрытия по скроллу;
- idle-анимацию;
- реакцию на курсор;
- движение внутренних колец;
- появление data-линий и импульсов;
- читаемость модели при разных размерах экрана;
- производительность и fallback.

## 2. Источник состояний

Анимация модели занимает 4 секунды и соответствует кадрам Blender 1–120.

- `0.033 сек` — собранная сфера;
- `1.167 сек` — hover / ожидание;
- `2.500 сек` — частичное раскрытие;
- `4.000 сек` — System Mode.

## 3. Механика

### Idle

- модель остаётся собранной;
- вся сфера очень медленно поворачивается;
- лёгкое вертикальное дыхание;
- ядро мягко меняет интенсивность;
- без самопроизвольного раскрытия.

### Курсор

- камера отклоняется не более чем на 4–5 градусов;
- объект смещается на несколько пикселей по глубине;
- при близости курсора к сфере состояние плавно двигается от `closed` к `hover`;
- после ухода возвращается назад.

### Скролл

- scroll progress управляет временем структурной анимации;
- движение не проигрывается автоматически, а строго scrub-синхронизировано;
- переходы между ключевыми состояниями сглаживаются;
- после 75% активируются подписи модулей;
- после 82% импульсы по линиям начинают двигаться независимо от остановки скролла.

### QA-переключатели

Viewer содержит четыре кнопки для перехода к состояниям:

1. Собрана;
2. Hover;
3. Частично;
4. System.

Кнопки нужны только для тестирования и не попадут в Hero.

## 4. Визуальная среда

- фон: Slate / deep graphite;
- акцент: Electric Teal;
- никаких карточек SaaS;
- сфера — единственный главный объект;
- poster показывается до загрузки WebGL;
- после загрузки poster плавно исчезает;
- внешние подписи — HTML, внутренние линии — часть GLB.

## 5. Производительность

- DPR desktop: максимум 1.6;
- DPR mobile: максимум 1.2;
- antialias отключается на мобильных;
- Canvas не пересоздаётся;
- при `prefers-reduced-motion` фиксируется мягкое частичное состояние;
- при ошибке загрузки остаётся poster и показывается понятная диагностика.

## 6. Критерии приёмки

- нет бесконечного loader;
- модель не обрезается на 1366×768 и 1920×1080;
- закрытая сфера читается сразу после загрузки;
- hover не выглядит как раскрытие;
- partial и system совпадают по характеру с рендерами V6;
- при system линии и импульсы живут после остановки скролла;
- нет резких скачков при прокрутке назад;
- FPS визуально стабилен на desktop;
- мобильная версия не ломает композицию.

## 7. Что не входит в V1

- Hero-тексты и навигация BND.STUDIO;
- GSAP / Lenis;
- страницы проектов;
- контактный сборщик;
- финальная оптимизация GLB через Meshopt/KTX2;
- bloom-постобработка.
