# AI Sphere Hero — WebGL-контрольный прототип

Отдельный прототип новой главной BND.STUDIO. Текущая рабочая версия сайта не изменяется.

## Что проверяем

- реальную процедурную Three.js-сферу в палитре Slate + Electric Teal;
- объёмные изогнутые сегменты оболочки вместо плоских CSS-пластин;
- спокойную idle-анимацию ядра, колец, оболочки и потоков данных;
- реакцию сцены и типографики на курсор;
- раскрытие сферы и появление системных связей по прокрутке;
- подписи модулей: AI / ИИ, DATA / ДАННЫЕ, API, UI / ИНТЕРФЕЙС;
- мобильную упрощённую композицию;
- полноэкранный интерактивный сборщик задачи;
- режим `prefers-reduced-motion`.

## Запуск

Прототип использует ES-модуль Three.js, поэтому его нужно открывать через локальный статический сервер.

Из корня репозитория:

```bash
python -m http.server 8000
```

После этого откройте:

```text
http://localhost:8000/prototype/ai-sphere/
```

Для загрузки Three.js требуется подключение к интернету.

## Что происходит со сферой

1. При загрузке она почти полностью собрана и медленно живёт: вращается, пульсирует и передаёт сигналы.
2. При движении мыши меняется перспектива и глубина слоёв.
3. При прокрутке серебристая оболочка становится прозрачнее, сегменты расходятся, внутренние кольца раскрываются.
4. Между ядром и модулями появляются световые линии данных и движущиеся импульсы.
5. На мобильных снижается количество сегментов, узлов и связей.

## Статус

Это контрольный WebGL-прототип на чистом Three.js. После утверждения движения и геометрии сцена будет перенесена в Next.js / React Three Fiber и встроена в общую архитектуру сайта.
