# AI Sphere Hero — контрольный прототип

Отдельный прототип новой главной BND.STUDIO. Текущая рабочая версия сайта не изменяется.

## Что проверяем

- фирменную модульную AI-сферу в палитре Slate + Electric Teal;
- спокойную idle-анимацию ядра, колец и оболочки;
- реакцию сцены и типографики на курсор;
- раскрытие сферы и появление связей по прокрутке;
- русские названия модулей: ИИ, Данные, API, Интерфейс;
- мобильную упрощённую композицию;
- полноэкранный интерактивный сборщик задачи;
- режим `prefers-reduced-motion`.

## Запуск

Откройте `index.html` через локальный статический сервер. Например:

```bash
python -m http.server 8000
```

После этого откройте `/prototype/ai-sphere/`.

## Ограничение прототипа

Сфера сделана процедурно средствами HTML/CSS/SVG и служит для проверки композиции и motion-сценария. В финальной версии объект будет перенесён в React Three Fiber / Three.js с полноценной геометрией, материалами и адаптивным уровнем детализации.
