# BND AI Core Hero V2

Вторая контрольная версия Hero после подтверждения scroll-механики V1.

## Что изменено

- шапка, заголовок, подзаголовок и кнопки вынесены в реальные HTML-слои;
- четыре утверждённых мокапа используются только как источник состояний куба;
- правая сцена обрезана и замаскирована вокруг куба, поэтому текст больше не двоится;
- добавлены интерактивные модули `AI`, `WEB`, `API`, `TELEGRAM`, `DATA`, `AUTOMATION`;
- hover/focus подсвечивает подпись, линию и связанную точку внутри ядра;
- клик переводит к следующему смысловому разделу;
- добавлен первый макет секции «ЧТО МОЖНО ИЗМЕНИТЬ»;
- предусмотрена мобильная композиция.

## Проверка

Полный локальный пакет с PNG-ассетами находится в ZIP из чата. Запуск: `start-viewer.bat`, затем открыть `http://localhost:8000`.

## Ограничение V2

Между состояниями пока выполняется короткий crossfade четырёх утверждённых кадров. Для полностью бесшовного раскрытия в V3 потребуется последовательность из 24–48 промежуточных кадров одного согласованного куба.

Рабочий сайт и ветка `main` не изменены.
